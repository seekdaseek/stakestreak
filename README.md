# StakeStreak

Social accountability challenge for Solana Seeker. Friends stake equal SOL into a pot, check in daily — miss a day and you're out, survivors split the whole pot.

- Skill-based: outcomes depend entirely on your own daily actions
- Escrowed stakes, 3% service fee on settlement
- Streak freezes, invite links, full refund before a pot starts
